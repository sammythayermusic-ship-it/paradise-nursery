# Paradise Nursery

Paradise Nursery is a shopping cart application for an online plant shop. Visitors land on a home page, browse houseplants grouped into categories, add plants to a cart and manage the cart.

## Features

- Landing page with the company name, a short About Us section and a Get Started button
- Product listing with three categories and six plants each, with thumbnail, name and price
- Add to Cart buttons that disable once a plant is added
- Navbar on the product and cart pages with links to Home, Plants and Cart
- Cart icon that shows the total number of items
- Cart page with per-plant subtotal, total cost, quantity buttons, delete, checkout and continue shopping

## Built with

React, Redux Toolkit and Vite.

## Run it

npm install
npm run dev
